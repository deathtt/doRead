How it works

Tasks: type in the bar and press +. Max 15 items. Tap the circle to finish, › to move between lists, × to delete.

Image button: choose any picture. It becomes 1-bit black and white. ⤓ downloads it as a PNG.

Portfolio: fill in your details, add a photo, pick a style, save it to your showcase and download it as a web page.

Files: open any file, edit it, save in another format. Use Paste to insert clipboard text. ▶ Run executes Python (Pyodide) or JavaScript — Ctrl/Cmd+Enter also runs. First Python run loads the runtime (~10–20s).
